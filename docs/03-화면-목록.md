## 공통 화면 구성

```
┌──────────────────────────────────────────────────────┐
│ 로고 · 시스템명            알림(3) · 홍길동(개발팀) · 로그아웃 │  ← 헤더
├────────────┬─────────────────────────────────────────┤
│ 대시보드     │  화면 제목                    [버튼들]     │
│ 구매요청     │  ┌ 검색 조건 ─────────────────────────┐  │
│ 결재함 (2)   │  └─────────────────────────────────────┘  │
│ 발주·재고    │  ┌ 목록 / 입력 폼 ─────────────────────┐  │
│ 기준정보     │  │                                     │  │
│ 관리자       │  └─────────────────────────────────────┘  │
│ (역할별 노출) │  < 1 2 3 >                               │
└────────────┴─────────────────────────────────────────┘
```

- 왼쪽 메뉴는 `menu_role` 기준으로 역할마다 다르게 보입니다.
- 목록 화면은 모두 "검색 조건 → 목록 → 페이징" 같은 틀을 씁니다(4단계 공통 기능).
