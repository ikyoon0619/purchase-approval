# 트러블슈팅 기록

개발하면서 실제로 막혔던 문제를 한 파일에 하나씩 남깁니다. 각 파일은 아래 틀을 따릅니다.

```markdown
# 제목 (한 줄로 무슨 문제였는지)

- 단계: N단계 / 관련 PR: #
- 키워드: JPA, N+1, ...

## 상황
무엇을 하려고 했는지

## 증상
에러 메시지, 로그, 화면 (그대로 붙여 넣기)

## 원인
왜 그런 일이 생겼는지

## 해결
무엇을 바꿨는지 (코드 조각)

## 전후 비교
쿼리 수, 실행 시간, 테스트 결과 같은 숫자

## 배운 점
다음에 같은 상황이면 무엇을 먼저 볼지
```
